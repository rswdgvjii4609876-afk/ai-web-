## 已实现的代码改造

- 保留网页注册与登录，共用桌面业务接口；登录和注册表单增加标签关联、自动填充、16px 输入字体与手机边距。
- 860px 及以下启用“工作台 / 面试 / 学习 / 我的”底部导航和可展开菜单；面试页隐藏底部导航。增加安全区、键盘焦点与页面滚动复位处理。
- 工作台入口排成两列，减少重复入口，长岗位名换行、状态标签保持完整。
- 面试训练重点默认折叠，输入获得焦点时收起训练重点；根据可视视口高度调整面试区域。长评分反馈限制高度并独立滚动，防止软键盘场景挤出发送按钮。
- 增加用户留言页面、列表分页、提交状态、错误重试和管理员回复展示。提交失败保留输入，提交中禁止编辑和重复提交。
- 增加独立后台留言列表、状态筛选、回复和关闭操作。沿用现有内容管理权限：根管理员或 `can_manage_admins`，前端入口与后端权限同时校验。
- 新增 `feedback` 数据表与 Alembic 迁移，服务器根据登录身份写入归属；用户只能读取自己的留言，跨用户编号返回 404。正文按纯文本渲染，不开放用户 HTML。

## 复现检查

后端目录安装测试依赖后运行：

```text
python -m pip install -r requirements-test.txt
python -m pytest tests/test_feedback.py tests/test_admin_permissions.py tests/test_security_hardening.py -q
python -m alembic heads
python -m alembic upgrade ab4c9d2e7f01:c719af032001 --sql
```

分别在 `ai-interview-frontend` 和 `ai-interview-admin` 运行 `npm ci`、`npm run build`。浏览器检查需要本机 Microsoft Edge；先分别启动用户前台（3019 端口）与管理后台（3020 端口）：

```text
npm run dev -- --host 127.0.0.1 --port 3019
npm run dev -- --host 127.0.0.1 --port 3020
```

随后进入 `scripts/mobile-web`，执行 `npm install`、`npm test`。四个脚本会使用隔离的模拟 API，输出 JSON 和截图到当前目录；后端无需启动。Playwright 版本取自本轮已验证的本机运行库。
