# 流程图与页面截图清单

## 核心流程图 1：从一份简历到一轮训练计划

```text
上传简历
  -> 解析经历和技能
  -> 选择目标岗位
  -> 对照岗位画像
  -> 证据诊断
     -> 有明确证据
     -> 有相关经历
     -> 只声明待验证
     -> 暂无证据
  -> 难度分层面试
  -> 面试报告
  -> 勾选能力项
  -> 生成学习计划
  -> 执行任务和笔记
  -> 训练复盘 / 下一轮验证面试
```

旁路控制面：

```text
后台治理
  -> 授权来源
  -> 人工复核
  -> PII 检查
  -> 样本门禁
  -> 评测与微调数据基础
```

## 核心流程图 2：AI 原生产品结构

```text
用户输入层：简历、目标岗位、面试回答、学习笔记
知识层：岗位画像、RAG 数据库、面经、能力项、学习资料
推理生成层：简历诊断、面试追问、评分报告、学习计划
控制层：结构化输出、JSON 修复、超时兜底、证据约束
治理层：授权、人工复核、PII 检查、导出门禁、评测样本
```

## 核心流程图 3：五层创新体系

```text
岗位画像与 RAG 数据库
        |
简历证据诊断
        |
难度分层 AI 面试
        |
报告到学习计划闭环
        |
评测与模型优化数据治理链路
```

## 页面截图清单

### 用户端截图

1. 简历上传页：显示目标岗位和难度选择。
2. 能力诊断页：显示能力状态和证据分类。
3. 简历润色页：显示证据约束型优化建议。
4. 面试页：显示左侧训练重点、中间对话、右侧评分记录。
5. 报告页：显示分数、能力短板、待验证点和训练建议。
6. 学习计划页：显示计划目标、任务步骤、笔记和下一步行动。

### 后台截图

1. 案例标注页：显示案例状态、授权、人工分和复核状态。
2. 资料包预检页：显示 PII 检查或样本门禁。
3. 岗位画像管理页：显示公共岗位画像和知识切片。

### PPT 页序建议

1. 项目一句话定义。
2. 大学生求职训练痛点。
3. 产品闭环流程图。
4. 现场演示：简历解析与证据诊断。
5. 现场演示：难度分层面试。
6. 现场演示：报告到学习计划。
7. 三个关键创新：岗位画像驱动、证据约束、报告转训练。
8. 技术可信度：结构化输出、RAG、兜底、治理门禁。
9. 完成度边界与应用价值。
10. 一年内落地路线。
