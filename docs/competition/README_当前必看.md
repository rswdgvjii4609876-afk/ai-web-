## 当前操作顺序

1. 服务器更新：
   ```bash
   cd /opt/apps/ai-interview
   git pull
   docker compose up -d --build
   docker compose exec -T app alembic upgrade head
   ```
2. 前端硬刷新或无痕登录，确认 DeepSeek 模型下拉只显示 V4 Pro / V4 Flash。
3. 用一份技能栏包含 FastAPI / Redis / Docker 的简历跑解析，确认能力诊断显示“技能声明分 / 证据深度分”，已声明技能显示为“声明待验证”。
4. 用同一份简历分别启动 easy / medium / hard 面试，确认题目深度递进：easy 不提前追问高并发/RAG，medium 追问项目职责和取舍，hard 深挖系统设计、可靠性和复杂工程场景。
5. 面试页实测连续答题：回答一题后输入框仍可见，评分条可关闭/展开，消息中的 HTML 只作为文本显示。
6. 后台实测“案例标注”：未授权 completed 案例可打开结构化补授权弹窗，填写原因后再保存人工标注。
7. 用户端人工上传简历，按顺序完成：
   ```text
   简历解析 -> 简历润色 -> 新建面试 -> 回答面试 -> 生成报告 -> 训练复盘
   ```
8. 后台进入“案例标注”，只标注人工跑出的有效 completed 案例。
9. 满足已完成、已授权/管理员补授权、人工复核和 PII 门禁后，再考虑 OpenAI SFT 数据准备。
